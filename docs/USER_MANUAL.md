# User Manual / คู่มือการใช้งาน

Hospital Triage & Critical Medical Equipment Allocator

## 1. Install and run / ติดตั้งและเปิดโปรแกรม

1. Install JDK 17 or newer. Check with `java -version`.
2. Open a terminal in the `HospitalTriage` folder.
3. Run `run.bat` (Windows) or `./run.sh` (macOS/Linux). The script compiles the
   source into `out/` and opens the GUI.

ติดตั้ง JDK 17 ขึ้นไป เปิดเทอร์มินัลในโฟลเดอร์ `HospitalTriage` แล้วรัน `run.bat` หรือ `./run.sh`

**From an IDE:** open the `HospitalTriage` folder as a project and run `hospital.Main`.
In NetBeans use *File → Open Project*, then *Run (F6)*.

The program starts with sample data: 6 patients, 4 staff and 12 devices.
โปรแกรมโหลดข้อมูลตัวอย่างให้ (ผู้ป่วย 6 คน บุคลากร 4 คน อุปกรณ์ 12 ชิ้น)

## 2. ESI levels / ระดับความเร่งด่วน

| Level | Meaning | ความหมาย | Target wait |
|---|---|---|---|
| ESI 1 | Resuscitation | กู้ชีพทันที | 0 min |
| ESI 2 | Emergent | ฉุกเฉินวิกฤต | 10 min |
| ESI 3 | Urgent | เร่งด่วน | 30 min |
| ESI 4 | Less urgent | ไม่รุนแรง | 60 min |
| ESI 5 | Non-urgent | ไม่เร่งด่วน | 120 min |

Patients under 15 are assessed with the pediatric protocol.

## 3. GUI walkthrough / การใช้งานหน้าจอ

The top bar shows the acting staff member and the simulated clock
(**+15 min**, **+1 hour**). Pick a doctor as the acting staff member before
allocating a ventilator or defibrillator.

แถบด้านบนใช้เลือกผู้ปฏิบัติงานและเลื่อนเวลาจำลอง ต้องเลือกแพทย์ก่อนจัดสรรเครื่องช่วยหายใจหรือเครื่องกระตุกหัวใจ

### Tab 1 – Triage & Queue / คัดกรองและคิว

1. Fill in the form: name, age, chief complaint, vital signs, pain score,
   consciousness (AVPU), expected resources, and high-risk flag.
2. **Read bedside monitor** fills the vital signs from the simulated legacy monitor.
3. **Admit & triage** assesses the patient and adds them to the queue. The ESI
   level and the reasons are shown.
4. **Call next patient** moves the most urgent patient into treatment and
   allocates the recommended equipment.
5. **Re-triage with form vitals** re-assesses the selected patient with new values.
6. **Details** (or double-click a row) shows the full assessment.

### Tab 2 – Treatment / การรักษา

- **Allocate**: give a device type to the selected patient. If none are free,
  the system tries to take one from a less urgent patient.
- **Release...**: return one of the patient's devices.
- **Discharge**: release all of the patient's equipment and discharge them.

### Tab 3 – Equipment / อุปกรณ์

- **Add device**: create a new device of the chosen type.
- **Start maintenance** / **Complete maintenance**: a device in use cannot go
  into maintenance.
- **Release from patient**: free a device directly.

### Tab 4 – Reports & Log / รายงาน

- **Daily report**: summary of patients, equipment use, and costs.
- **Shortage check**: lists patients waiting for equipment that is not available.
- **OOP concept demo**: prints the concept demonstration into the log.
- **Clear log**.

## 4. Allocation rules / กฎการจัดสรรอุปกรณ์

1. A free device that is not under maintenance is used first.
2. If none is free, the device is taken from the holder with the lowest
   urgency, but only if that holder is **strictly** less urgent (higher ESI number).
   Between equal holders, the one who arrived later gives it up.
3. Life-support devices (ventilator, defibrillator) need a **doctor** and an
   **ESI 1–2** patient.
4. Every allocation, release, and pre-emption is written to the audit log.

## 5. Console mode / โหมดคอนโซล

Run `run.bat --console` (or `./run.sh --console`) and type a menu number:

```
 1 Admit & triage patient     8 Show equipment
 2 Show waiting queue         9 Advance clock
 3 Call next patient         10 Daily report
 4 Show patients in treatment 11 Change acting staff
 5 Allocate equipment        12 Read bedside monitor
 6 Release equipment         13 OOP concept demonstration
 7 Discharge patient          0 Exit
```

## 6. Tests and demo / การทดสอบ

- `run.bat --test` runs 35 automated tests and prints `35 passed, 0 failed`.
- `run.bat --demo` prints a walk-through of each OOP concept used in the project.

## 7. Troubleshooting / แก้ปัญหา

| Problem | Fix |
|---|---|
| `javac` not found | Install a JDK (not only a JRE) and add it to `PATH`. |
| Thai text shows as `?` in the console | Console output is English only; use the GUI for Thai. |
| GUI does not open on a server without a display | The program switches to console mode automatically. |
| NetBeans asks to regenerate build files | Accept; `nbproject/build-impl.xml` is generated by NetBeans. |
